# VRLog Updates

VRLogの無料配布と自動更新用リポジトリです。最新版の完全なインストーラーは[Releases](https://github.com/YUMA0906/VRLog-Updates/releases/latest)から取得できます。

## 最新版

- バージョン: `0.0.66`
- インストーラー: `VRLog-0.0.66-Installer-UNSIGNED.exe`
- SHA-256: Releaseの `SHA256SUMS.txt`

このプレビュー配布物には、信頼済みCAによるWindows Authenticode署名がありません。Windowsが発行元を確認できない、又は実行を止める場合があります。Smart App Control、SmartScreen、ウイルス対策を無効化せず、取得元とSHA-256を確認してください。

`releases.win.json`、その署名、`*-full.nupkg`、`*-delta.nupkg` はVRLogの自動更新で使用します。更新フィードはアプリ内の公開鍵で検証されます。更新署名は配布データの改ざん検知用で、Windows Authenticodeとは別です。

VRLog本体の再配布、改変版の配布及び名称を利用した誤認表示は利用規約で禁止しています。第三者OSSのライセンス上認められた権利は、それぞれのライセンスに従います。
